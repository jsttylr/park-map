Anyone who can open this page can change these settings. Set PARK_MAP_ADMIN_PASSWORD on the container to require a password.

General

Messages from anyone else are ignored and logged. Every inReach sends from Garmin's shared address no.reply.inreach@garmin.com, so a PIN is required for those. The PIN can be a word in the message, or part of the address you send to: with Gmail, save the contact as yourbox+7373@gmail.com and you never have to type it.

Incoming mail (IMAP)

Use a mailbox just for this. Unread messages are handled and marked read. For Gmail, turn on 2-step verification and use an app password.

Outgoing mail (SMTP)

Only used to answer messages sent from ordinary email, which is handy for testing for free. inReach messages are answered through Garmin.

POTA spots

POTA's spot service doesn't take a login; spots are posted under your callsign.
